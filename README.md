# 🔴 Martian Map — Explore the Red Planet

**An interactive 3D exploration platform for Mars.**

Martian Map is a web-based planetary exploration application designed to make exploring the Martian surface more interactive and accessible. Built using CesiumJS, the platform provides a 3D Mars globe, scientific imagery layers and interactive exploration of important Martian locations.

## 🚀 Features

- **Interactive 3D Mars Globe:** Explore Mars through an interactive planetary visualization.
- **Scientific Imagery Layers:** Switch between available Mars imagery sources, including MOLA and THEMIS.
- **Mars Location Explorer:** Explore important Martian locations with geographical coordinates and scientific descriptions.
- **Interactive Navigation:** Zoom, rotate and navigate across the Martian surface.
- **Imagery Selection:** Switch between available visualization layers.
- **Scientific Exploration:** Discover Martian terrain and geological features through available imagery and location information.

## 🛰️ Scientific Data Sources

The application currently supports:

| Data Source | Description |
|---|---|
| MOLA | Mars Orbiter Laser Altimeter data for topographic and elevation visualization. |
| THEMIS | Thermal Emission Imaging System imagery for exploring Martian surface features. |

Additional scientific datasets are being evaluated for potential integration.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- A modern web browser

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd martian-map
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 🌌 Project Objective

The objective of Martian Map is to provide an interactive platform for exploring Mars through 3D visualization, scientific imagery and geographical information.

By bringing planetary visualization and location-based exploration together, the project aims to make Martian surface exploration more intuitive and engaging.
